# Домашнє завдання (Модуль 1)

## Мета

Закріпити навички роботи з Expo-проєктом, навчитися створювати кілька екранів, використовувати навігацію між ними, працювати з зображеннями та стилізацією компонентів.

## Завдання

1. **Підготовка проєкту:**
   - Виконайте `npx create-expo-app@latest LessonOne`
   - Перейдіть у папку `cd LessonOne`
   - Очистіть шаблон (якщо ще не зробили): `npm run reset-project`
   - Запустіть проєкт: `npm start`

2. **Головний екран (`index.tsx`):**
   - Створіть головний екран додатка з використанням `SafeAreaView`, `View`, `Text`.
   - Додайте заголовок додатка та короткий опис.
   - Додайте кнопку або посилання **"Про мене"**, яке веде на сторінку "Про себе".
   - Застосуйте базову стилізацію: фон, відступи, вирівнювання, кольори.

3. **Сторінка "Про себе" (`about.tsx`):**
   - Створіть новий файл `about.tsx` у папці `app`.
   - Додайте своє **фото** за допомогою компонента `Image` (фото можна розмістити у папці `assets/images`).
   - Додайте **коротку інформацію про себе**: ім'я, хобі, улюблена мова програмування тощо.
   - Використайте компоненти `SafeAreaView`, `View`, `Text`, `Image`, `ScrollView`.
   - **Стилізуйте сторінку**: задайте розміри та округлення для фото, відступи, шрифти, кольори фону та тексту.
   - Додайте кнопку або посилання **"Повернутися назад"**, яке веде на головну сторінку.

4. **Навігація між екранами:**
   - Використайте файлову маршрутизацію Expo Router для переходу між `index.tsx` та `about.tsx`.
   - Для навігації використовуйте компонент `Link` з `expo-router`.
   - Переконайтесь, що навігація працює в обидва боки:
     - З головної → на "Про себе"
     - З "Про себе" → назад на головну

5. **Стилізація:**
   - Обидва екрани повинні мати **узгоджений дизайн** (спільна кольорова палітра, шрифти, відступи).
   - Фото повинно бути округленим або з рамкою.
   - Кнопки навігації повинні бути стилізовані (не стандартний `Button`), використовуйте `TouchableOpacity` або `Pressable`.

6. **Результати:**
   - Надішліть викладачу лінк на GitHub репозиторій або Zip.
   - Додайте скріншоти обох екранів (головний та "Про себе").
   - Напишіть короткий звіт (не більше 150 слів) про виконану роботу.

## Підказки

- Для навігації між сторінками у Expo Router достатньо створити файли у папці `app/` — кожен файл автоматично стає маршрутом.
- Приклад використання `Link`:

  ```tsx
  import { Link } from 'expo-router';

  <Link href="/about" style={styles.link}>Про мене</Link>
  <Link href="/" style={styles.link}>Повернутися назад</Link>
  ```

- Приклад використання `Image`:

  ```tsx
  import { Image } from "react-native";

  <Image
    source={require("../assets/images/my-photo.jpg")}
    style={{ width: 150, height: 150, borderRadius: 75 }}
  />;
  ```

## Критерії оцінювання

- Проєкт запускається без помилок
- Головний екран містить заголовок, опис та посилання на сторінку "Про себе"
- Сторінка "Про себе" містить фото та коротку інформацію
- Навігація працює в обидва боки (туди і назад)
- Обидва екрани стилізовані з використанням `StyleSheet`
- Код чистий та структурований
