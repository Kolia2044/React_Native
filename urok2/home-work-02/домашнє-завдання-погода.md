# Домашнє завдання: Додаток "Погода"

## Мета завдання

Створити React Native додаток для відображення поточної погоди з використанням TypeScript та OpenWeatherMap API. Це завдання допоможе закріпити знання з типізації компонентів, роботи з API, стану додатку та обробки помилок.

---

## Технічні вимоги

### 1. API Integration

Використовуйте **OpenWeatherMap API** для отримання даних про погоду:

- Базовий URL: `https://api.openweathermap.org/data/2.5/weather`
- Документація: https://openweathermap.org/current
- Вам потрібно зареєструватися та отримати безкоштовний API ключ

**Приклад запиту:**

```
https://api.openweathermap.org/data/2.5/weather?q=Kyiv&appid=YOUR_API_KEY&units=metric&lang=ua
```

### 2. Структура проєкту

Створіть наступні компоненти з правильною типізацією:

```
app/
├── index.tsx                    # Головний екран
components/
├── WeatherCard.tsx              # Картка з інформацією про погоду
├── SearchInput.tsx              # Поле для введення назви міста
├── LoadingSpinner.tsx           # Індикатор завантаження
└── ErrorMessage.tsx             # Компонент для відображення помилок
types/
└── weather.ts                   # Типи для даних погоди
```

## Підказки

### Безпека API ключа

**НЕ** зберігайте API ключ безпосередньо в коді! Використовуйте змінні середовища:

1. Створіть файл `.env` в корені проєкту:

```
EXPO_PUBLIC_WEATHER_API_KEY=ваш_api_ключ
```

2. Додайте `.env` до `.gitignore`

3. Використовуйте в коді:

```tsx
const API_KEY = process.env.EXPO_PUBLIC_WEATHER_API_KEY;
```

### Приклад fetch запиту

```tsx
const response = await fetch(
  `https://api.openweathermap.org/data/2.5/weather?q=${city}&appid=${API_KEY}&units=metric&lang=ua`,
);

if (!response.ok) {
  throw new Error("Місто не знайдено");
}

const data = await response.json();
```

### Обробка помилок

```tsx
try {
  // fetch логіка
} catch (error) {
  if (error instanceof Error) {
    setError({ message: error.message });
  } else {
    setError({ message: "Невідома помилка" });
  }
}
```
